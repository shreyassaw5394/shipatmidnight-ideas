# Ship at Midnight · ideas

What should ship next? This repo holds only the ideas board for [shipatmidnight.dev](https://shipatmidnight.dev): no code.

- **Vote** with a 👍 reaction on an idea's issue. The board on the site sorts by those counts.
- **Suggest** a new idea with the [Idea form](../../issues/new?template=idea.yml), or tell us in [Discord](https://discord.gg/s8wj7tBAM).
- Bugs and feedback on a tool that already shipped go to that tool's own repo.

Ship at Midnight is a free, non-commercial passion project by an independent developer.
